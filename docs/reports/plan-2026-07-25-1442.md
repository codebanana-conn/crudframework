### ✅ Hạng mục 3 — Tự động hoá Designer cho binding

- **Vấn đề:** `EntityType`/`EntityTypeName` không hiện dropdown chọn entity trong Properties Grid.
- **Cách giải quyết:**
  - Điều tra `DesignTimeSupport.cs`: tìm 3 nguyên nhân (1. `EntityTypeName` thiếu TypeConverter+Editor, 2. `EntityType` thiếu Editor, 3. `EntityBindingSource.EntityType` thiếu TypeConverter).
  - Fix: thêm `[TypeConverter]`+`[Editor]` đúng property, tạo `EntityTypeUIEditor` dropdown.
  - Ghi rõ giới hạn nền tảng: VS Designer cần Build Solution trước mở Designer lần đầu;
    dropdown rỗng nếu chưa build → fallback gõ EntityTypeName FullName 1 lần/entity.
- **Kết quả:** 3 attribute fix + 1 UITypeEditor mới. Trung thực: **KHÔNG** tự động hoá 100%
  (giới hạn VS/WinForms Designer — ITypeDiscoveryService + AppDomain load).
- **Trạng thái:** ✅ xong (đã fix lỗi phát sinh khi chọn combo — xem bên dưới).
- **Fix lỗi phát sinh (`Object of type 'System.String' cannot be converted to type 'System.Type'`):**
  - Nguyên nhân: `EntityTypeUIEditor.EditValue` xác định `isTypeProperty = value is Type`;
    khi `value == null` (ban đầu) → `false` → editor trả **chuỗi** cho property kiểu `Type` → lỗi ép kiểu.
  - Fix: xác định `isTypeProperty` từ `context.PropertyDescriptor.PropertyType`; với property kiểu
    `Type`, item bọc bằng lớp `EntityTypeListItem` (giữ Type thật, hiển thị `Type.Name`) và trả về
    đúng đối tượng `Type`; property `EntityTypeName` (string) vẫn trả FullName. Bổ sung `[Editor]`
    cho `EntityBindingSource.EntityType` cho nhất quán. Cập nhật `docs/developments.md` mục 3.
- **Cải tiến:** Có thể thêm naming convention auto-bind (`txtCustomerCode` → `CustomerCode`)
  ở bản sau, nhưng cần cân nhắc độ phức tạp vs lợi ích.
